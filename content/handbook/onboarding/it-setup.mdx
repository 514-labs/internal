# IT Setup Guide

This guide walks you through setting up your development environment and accessing company systems.

## Required Software

Install the following on your machine:

### Development Tools

- **Git** - Version control
- **VS Code** or **Cursor** - Code editor
- **Node.js** (LTS version) - JavaScript runtime
- **Docker** - Containerization

### Communication

- **Slack** - Team chat
- **Zoom** - Video calls
- **Google Workspace** - Email and documents

## Account Access

You should have received invitations to:

1. Google Workspace (email)
2. Slack workspace
3. GitHub organization
4. Linear (project management)
5. 1Password (password manager)

## VPN Setup

For accessing internal services, you'll need to set up the VPN:

1. Download the VPN client from IT portal
2. Import your configuration file
3. Connect using your SSO credentials

## Getting Help

If you run into issues, reach out to the #it-help Slack channel.
