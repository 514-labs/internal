# User Persona Qualification

Our user persona qualification framework categorizes potential users across three tiers based on their likelihood to succeed with and derive value from our platform.

---

## Tier Overview

| Tier | Name | Score | Focus |
|------|------|-------|-------|
| **Tier 1** | Core | +1 | Primary target audience |
| **Tier 2** | Adjacent | 0 | Secondary audience with potential |
| **Tier 3** | Ignore | -1 | Not a priority |

---

## Qualification Matrix

| Criteria | Tier 1/Core (+1) | Tier 2/Adjacent (0) | Tier 3/Ignore (-1) |
|----------|------------------|---------------------|-------------------|
| **Title** | Senior+ Software Engineer | Architect, data engineer, platform engineer, Engineering Manager+, SRE (building ClickHouse O11y App) | ... |
| **Demographics** | English, Works at Tier 1 company | French, Works at Tier 2 or 3 company | Other languages |
| **Skill** | Terminal usage + IDE, Intermediate+ TS (including monorepo?), AI-enabled development, SQL comfort (could be LLM assisted) | Intermediate+ Python, Bonus: FastAPI | Other languages |
| **Hardware** | x86/arm linux + arm macs with 16+ GB ram | Other macs + Linux machines, Windows w/ WSL | Windows |
| **Software** | IDE + Copilot, Node 20+ & pnpm, Docker v.., Git + Github, (extra credit) Linear, Turborepo | Python 3.12+ pip (or UV?), Other (or no) monorepo tech, Node 20+ & npm | Other (or no) version control, Non-node runtimes (Deno, Bun) |
| **Cloud** | AWS/GCP | Azure | ... |
| **Success/goal** | Ship AI OLAP features, Ship user facing analytical features | Ship internal OLAP powered features, Increase adoption of OLAP platform in org | Internal BI / reporting only, Collect paycheck |

## How to Use This Framework

1. **Lead Scoring**: Use the tier scores to prioritize leads and opportunities
2. **Content Strategy**: Create content that resonates with Tier 1 personas first
3. **Feature Prioritization**: Build features that solve Tier 1 problems
4. **Support**: Invest more in Tier 1 customer success
5. **Marketing**: Target Tier 1 channels and communities
