# New Hire Onboarding Playbook

A step-by-step guide for managers to successfully onboard new team members.

## Before Day 1

### Week Before

- [ ] Confirm start date with HR
- [ ] Order equipment (laptop, monitor, etc.)
- [ ] Set up accounts (email, Slack, GitHub)
- [ ] Assign an onboarding buddy
- [ ] Create first week calendar with key meetings
- [ ] Prepare welcome materials

### Day Before

- [ ] Send welcome email with Day 1 agenda
- [ ] Confirm all accounts are ready
- [ ] Remind team about new hire

## Week 1

### Day 1

**Morning**
- Welcome meeting with manager (30 min)
- IT setup and account access
- Meet the team (virtual or in-person)
- Lunch with buddy

**Afternoon**
- Review team documentation
- Complete HR paperwork
- End-of-day check-in with manager

### Days 2-5

- Complete required training
- 1:1s with team members
- Start on starter project
- Daily check-ins with buddy

## Week 2

- Continue onboarding project
- Attend team ceremonies (standup, retro)
- Begin regular 1:1s with manager
- 30-day goal setting

## Success Metrics

By end of Week 2, new hire should:

- [ ] Have all required access
- [ ] Understand team's purpose and goals
- [ ] Have merged first PR (engineering) or completed first project
- [ ] Know who to ask for help
- [ ] Feel welcomed and included
