# Analytics Suite

The Analytics Suite provides powerful business intelligence and data visualization capabilities.

## Features

### Real-time Dashboards
Create and share interactive dashboards that update in real-time.

### Custom Reports
Build custom reports with our drag-and-drop report builder.

### Data Exploration
Explore your data with SQL or our visual query builder.

### Alerts
Set up alerts based on metric thresholds.

## Data Sources

Connect to multiple data sources:

- PostgreSQL, MySQL, SQL Server
- Snowflake, BigQuery, Redshift
- REST APIs
- CSV/Excel uploads

## Pricing

Available as an add-on to the Core Platform or standalone license.
