# RACI Matrix

RACI is a responsibility assignment matrix that clarifies roles and responsibilities.

## The Roles

### R - Responsible
The person(s) who do the work. There should be at least one person responsible for each task.

### A - Accountable
The one person who is ultimately accountable for the outcome. Only one person can be accountable.

### C - Consulted
People who provide input and whose opinions are sought before decisions are made. Two-way communication.

### I - Informed
People who are kept up-to-date on progress. One-way communication.

## Example

| Task | Product | Engineering | Design | Marketing |
|------|---------|-------------|--------|-----------|
| Define requirements | A | C | C | I |
| Design solution | C | R | A | I |
| Build feature | I | A/R | C | I |
| Write docs | C | R | I | A |

## Best Practices

1. Every task should have exactly one "A"
2. Minimize the number of "C"s to avoid decision paralysis
3. Use "I" liberally to keep people informed
4. Review and update regularly
